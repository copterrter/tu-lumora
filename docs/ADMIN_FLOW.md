# Admin Flow (หลังบ้าน) — Text Chart

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                              ENTRY & AUTH                                    │
└─────────────────────────────────────────────────────────────────────────────┘

    /admin
         │
         ▼
    [ ใส่รหัสผ่าน ]
         │
         ├──► ผิด ──► แจ้ง ACCESS DENIED, ใส่ใหม่
         │
         └──► ถูก (ADMIN_PIN) ──► fetch ออเดอร์ทั้งหมดจาก Supabase
                                       │
                                       ▼
                                  แสดง Dashboard


┌─────────────────────────────────────────────────────────────────────────────┐
│                           DASHBOARD OVERVIEW                                 │
└─────────────────────────────────────────────────────────────────────────────┘

    หลัง Login แสดง:
         │
         ├──► สถิติ: Total Orders, Total Revenue
         ├──► Units sold (T-SHIRT / CROP) — นับจากออเดอร์ paid + shipped
         ├──► กราฟ Revenue & Orders Overview (ตามวันที่เวลาไทย)
         ├──► Status Snapshot: Pending Manual / Paid & Verified / Shipped
         ├──► กราฟอื่น (Order Status, Product Breakdown ฯลฯ)
         └──► ตารางออเดอร์ + ปุ่มดำเนินการ


┌─────────────────────────────────────────────────────────────────────────────┐
│                        ORDER TABLE ACTIONS                                   │
└─────────────────────────────────────────────────────────────────────────────┘

    แต่ละแถวออเดอร์ แสดง: วันที่, ชื่อ, เบอร์, สินค้า, ยอด, สถานะ, สลิป (ถ้ามี)
         │
         ├──► สถานะ = pending_manual_verify
         │         │
         │         ▼
         │    [ อนุมัติสลิป / Mark as Paid ]
         │         │
         │         └──► POST /api/orders/approve { orderId }
         │                   │
         │                   ▼
         │              อัปเดต status → paid_and_verified
         │              ส่งเมลใบเสร็จ (ถ้ามี)
         │              refresh ตาราง
         │
         ├──► [ แก้ยอด ]
         │         │
         │         └──► รหัส Dev (dev101) ──► ใส่ยอดใหม่
         │                   │
         │                   └──► PATCH /api/orders/update-amount
         │
         ├──► [ ลบออเดอร์ ]
         │         │
         │         └──► รหัส Dev (dev101) ──► ยืนยัน
         │                   │
         │                   └──► POST /api/orders/delete
         │
         └──► ดูสลิป (ลิงก์ slip_image_url)


┌─────────────────────────────────────────────────────────────────────────────┐
│                     UPLOAD TRACKING (จัดส่ง)                                 │
└─────────────────────────────────────────────────────────────────────────────┘

    [ อัปโหลดไฟล์ Tracking ]
         │
         ▼
    เลือกไฟล์ (Excel/CSV) ──► ยืนยัน
         │
         ▼
    POST /api/upload-tracking (FormData: file)
         │
         │  จับคู่เลขพัสดุกับออเดอร์ (เบอร์/อีเมล ฯลฯ)
         │  อัปเดต orders.tracking_number
         │  ส่งอีเมลแจ้งเลขพัสดุให้ลูกค้า
         │
         ▼
    แสดงผล: จับคู่ได้ X ออเดอร์, ส่งเมล X ฉบับ
    refresh ตารางออเดอร์


┌─────────────────────────────────────────────────────────────────────────────┐
│                           EXPORT & อื่นๆ                                     │
└─────────────────────────────────────────────────────────────────────────────┘

    [ Export CSV ]
         │
         └──► ดาวน์โหลดไฟล์ CSV รายการออเดอร์ทั้งหมด (ฝั่ง client, ไม่เรียก API)

    หมายเหตุ:
    - รหัส Admin ใช้แค่ตรวจที่หน้า /admin (ไม่มี API แยก login)
    - รหัส Dev (dev101) ใช้สำหรับแก้ยอดและลบออเดอร์เท่านั้น (ส่งใน body ของ API)
```
