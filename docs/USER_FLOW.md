# User Flow (ลูกค้า) — Text Chart

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                              ENTRY POINTS                                    │
└─────────────────────────────────────────────────────────────────────────────┘

    [ เข้าเว็บ / ]
         │
         ├──► HOME (/)
         │         │
         │         ├──► [ SHOP / PRE-ORDER ] ──► /product
         │         ├──► MAGAZINE (external)
         │         ├──► CONTACT (LINE external)
         │         └──► ปุ่ม Pre-order / ดู Lookbook ฯลฯ
         │
         ├──► สแกน QR บูธ ──► /booth (ช่วง Normal เท่านั้น)
         │
         └──► เปิด /product, /checkout, /thankyou โดยตรง (หรือจากลิงก์)


┌─────────────────────────────────────────────────────────────────────────────┐
│                          SHOP / PRE-ORDER FLOW                               │
└─────────────────────────────────────────────────────────────────────────────┘

    /product (เลือกสินค้า)
         │
         │  เลือก Style (T-SHIRT / CROP), Size, จำนวน
         │  Add to Cart
         │
         ▼
    [ ไปชำระเงิน ] ──► /checkout
         │
         │  โหลดออเดอร์จาก localStorage (lumora_order)
         │  กรอก: ชื่อ, อีเมล, เบอร์, ที่อยู่, รหัสไปรษณีย์, IG/LINE
         │  (ช่วง Normal + ซื้อ 1 ตัว) ใส่โค้ดส่วนลด → กด Enter หรือคลิกออกจากช่อง → ตรวจอัตโนมัติ
         │  ยอมรับ PDPA + เงื่อนไขไม่คืนเงิน
         │  อัปโหลดสลิปโอนเงิน
         │
         ▼
    [ ส่งออเดอร์ ] ──► POST /api/verify (สลิป + ข้อมูลออเดอร์ + โค้ดถ้ามี)
         │
         ├──► อ่านสลิปได้ + ยอดตรง
         │         │
         │         ▼
         │    สร้างออเดอร์ status = paid_and_verified
         │    ถ้ามีโค้ดส่วนลด → อัปเดต promo_codes.is_used = true
         │    ส่งเมลใบเสร็จ
         │         │
         │         ▼
         │    redirect ──► /thankyou
         │
         └──► อ่านสลิปไม่ได้ / ยอดไม่ตรง (manual fallback)
                   │
                   ▼
              สร้างออเดอร์ status = pending_manual_verify
                   │
                   ▼
              redirect ──► /thankyou?manual=1 (แจ้งให้รอแอดมินตรวจ)


┌─────────────────────────────────────────────────────────────────────────────┐
│                              BOOTH FLOW                                      │
└─────────────────────────────────────────────────────────────────────────────┘

    /booth (เปิดได้เฉพาะ phase = Normal)
         │
         ▼
    [ สุ่มรางวัล ] ──► POST /api/booth/spin
         │
         ├──► 429 (รอ X วินาที) ──► แสดงนับถอยหลัง, ปุ่ม disabled
         │
         ├──► ได้ 10% / 15% / 50%
         │         │
         │         ▼
         │    แสดงโค้ดส่วนลด
         │    Copy Code / Save to Camera Roll
         │    [ ไปเลือกสินค้าและสั่งซื้อ ] ──► /product
         │    [ SHOP NOW ] ──► /product
         │    [ BACK TO HOME ] ──► /
         │
         └──► ได้ 0% (ลูโม่กินส่วนลด)
                   │
                   ▼
              แชร์ IG Story ปลดล็อก หรือรอ X วินาที แล้วสุ่มใหม่ได้


┌─────────────────────────────────────────────────────────────────────────────┐
│                         THANK YOU & EXTERNAL                                 │
└─────────────────────────────────────────────────────────────────────────────┘

    /thankyou
         │
         ├──► manual=1 → ข้อความรอแอดมินตรวจสลิป
         └──► ไม่มี query → ข้อความสั่งซื้อสำเร็จ, เช็คเมล
         │
         ▼
    [ BACK TO HOME ] ──► /
    [ ติดต่อ LINE ] ──► external

    /closed
         │
         ▼
    แสดงข้อความปิดรับออเดอร์แล้ว (ไม่มีปุ่มสั่งซื้อ)
```
